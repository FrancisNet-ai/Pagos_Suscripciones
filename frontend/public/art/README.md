# Arte de Nuvyra

`nuvyra-fluid.webp` es una ilustración abstracta original generada para el rediseño editorial de
Nuvyra el 27 de octubre de 2026. Representa mármol fluido en la paleta azul del proyecto; no contiene
texto, logotipos, productos ni recursos comerciales de terceros.

Se convirtió a WebP con calidad 84 y se eliminaron los metadatos para servirla desde el mismo origen.
El archivo original generado se conserva fuera de este repositorio. No es una captura de la aplicación.

El componente decorativo `WaveArtComponent` la comparte entre portada, acceso y tiendas sin portada
propia. No añadir contenido esencial dentro de la imagen.
